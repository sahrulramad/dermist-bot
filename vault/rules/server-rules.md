# Aturan Komunitas & Moderasi Server

Selamat datang di server! Harap patuhi aturan berikut agar komunitas tetap nyaman dan aman untuk semua member.

## 1. Sikap dan Etika Berkomunikasi
- Hormati sesama member dan moderator.
- Dilarang keras melakukan pelecehan (harassment), ujaran kebencian (hate speech), SARA, dan kata-kata kasar/toxic.
- Diskusi hangat diperbolehkan, tetapi jangan menyerang individu secara personal (ad hominem).

## 2. Aturan Anti-Spam dan Foto Spam
- Dilarang mengirimkan pesan berulang secara beruntun (> 5 pesan dalam 10 detik).
- **Foto Spam**: Dilarang memposting foto yang sama di berbagai channel sekaligus (cross-channel photo spam). Sistem auto-detect akan langsung memberikan peringatan dan menghapus pesan.
- Dilarang mengirim link promosi, undangan server Discord lain, atau link phising tanpa izin admin.

## 3. Sistem Peringatan dan Sanksi (Escalation)
Moderator dan bot menerapkan sistem eskalasi bertingkat:
- **1x Warning**: Teguran ringan dari bot / moderator.
- **2x Warning**: Mute / timeout selama 1 jam.
- **3x Warning**: Mute / timeout selama 24 jam.
- **4x Warning atau Lebih**: Kick atau Permanent Ban dari server.
- Warning akan kadaluarsa (decay) secara otomatis setelah 30 hari jika tidak ada pelanggaran berulang.

## 4. Penggunaan Bot AI (Dermist)
- Dermist dapat dipanggil dengan mention `@Dermist` di channel chat atau melalui slash command `/ask`.
- Dilarang mencoba melakukan prompt injection atau memaksa AI membocorkan rahasia sistem server.
