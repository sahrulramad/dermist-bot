# Skill: Pelaporan Pelanggaran & Bantuan Mod

## Kapan dipakai
Saat user ingin melaporkan member yang melanggar aturan, penipuan/scam di DM, spam mencurigakan, atau membutuhkan bantuan moderator.

## Panduan
- Tenangkan user dan apresiasi kepeduliannya menjaga server tetap aman.
- Tegaskan untuk TIDAK membalas atau terpancing melakukan doxxing/ribut di channel publik.
- Berikan panduan pelaporan yang efektif:
  1. Ambil tangkapan layar (screenshot) sebagai bukti yang jelas (tampilkan username, ID user jika bisa, dan pesan pelanggaran).
  2. Laporkan ke channel laporan/tiket (jika ada) atau hubungi langsung moderator/admin yang sedang online.
  3. Jika terjadi pelecehan atau scam via DM, sarankan juga memblokir user tersebut dan laporkan ke Discord Trust & Safety jika melanggar TOS.
- Ingatkan bahwa moderator memiliki command `/note add` untuk mencatat rekam jejak pelanggar dan `/warn`, `/mute`, `/ban` untuk menindaklanjuti.
