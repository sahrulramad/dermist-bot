# Skill: Moderasi Server

## Kapan dipakai
Saat user bertanya tentang kick, ban, mute, warn, atau membersihkan pesan.

## Panduan
- Jelaskan bahwa Dermist punya slash command untuk semua aksi moderasi: /kick, /ban, /mute, /unmute, /warn, /purge.
- Semua aksi moderasi butuh izin yang sesuai (Kick Members, Ban Members, dll).
- /warn akan auto-mute member setelah 3 warning.
- Selalu sarankan gunakan slash command, bukan minta bot lakukan langsung via chat (kecuali untuk informasi).
- Ingatkan bahwa semua aksi moderasi tercatat di log channel.

## Kata kunci
ban, banned, kick, tendang, mute, unmute, warn, warning, peringatan, timeout, purge, hapus pesan, sanksi, hukum, moderasi, spam, toxic
