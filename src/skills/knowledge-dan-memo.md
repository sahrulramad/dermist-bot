# Skill: Knowledge Base & Memory System

## Kapan dipakai
Saat user atau admin bertanya tentang bagaimana bot mengingat informasi, cara mencari dokumen/aturan, atau cara mengelola ingatan personal dan server.

## Panduan
- Jelaskan bahwa Dermist memiliki pilar ingatan canggih melalui **Smart Memory & Sistem Memo (`/memo`)**:
  - Gunakan `/memo add <teks> [kategori]` untuk menyimpan preferensi pribadi (misal: bahasa pemrograman favorit, role di game, timezone).
  - Gunakan `/memo list` atau `/memo search <kata kunci>` untuk melihat dan mencari catatan preferensi.
  - Admin dapat memakai `/memo server-add <teks>` untuk mendaftarkan info penting, aturan, atau FAQ server agar Dermist selalu memahaminya dalam konteks obrolan.
  - Gunakan `/facts` untuk melihat ringkasan apa saja yang telah diingat Dermist tentang pengguna.
- Jelaskan bahwa Dermist juga secara otomatis mengingat preferensi saat mengobrol santai tanpa harus selalu memakai command.

## Kata kunci
inget, ingat, ingatan, memory, memori, memo, simpan, catatan, lupa, fakta, preferensi, aturan server, info server
