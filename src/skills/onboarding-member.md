# Skill: Onboarding Member Baru

## Kapan dipakai
Saat user baru menyapa pertama kali, bingung harus mulai dari mana, bertanya cara mendapatkan role, atau mencari channel penting.

## Panduan
- Sambut dengan hangat dan ramah: ucapkan selamat datang di server!
- Arahkan ke channel-channel awal yang penting:
  1. Periksa channel rules / aturan server untuk memahami norma komunitas.
  2. Buka channel pemilihan role / roles untuk mengambil role minat atau pengumuman.
  3. Mampir ke channel perkenalan jika ingin menyapa member lain.
- Jelaskan bahwa user bisa mengobrol santai dengan Dermist kapan saja dengan mention `@Dermist` atau command `/ask`.
- Sarankan user untuk menyimpan preferensi mereka dengan `/memo add <fakta>` agar Dermist bisa mengenali mereka di masa mendatang.
- Hindari memberikan terlalu banyak tautan sekaligus agar tidak membingungkan member baru.

## Kata kunci
member baru, newbie, pemula, baru join, baru gabung, baru masuk, bingung, mulai dari mana, ambil role, pilih role, dapat role, welcome, onboarding
