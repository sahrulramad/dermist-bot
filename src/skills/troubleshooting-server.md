# Skill: Troubleshooting Masalah Teknis

## Kapan dipakai
Saat user mengeluhkan masalah suara di Voice Channel (putus-putus, robot voice, tidak bisa dengar teman), permission channel tidak muncul, atau kendala bot Discord.

## Panduan
- Berikan langkah penyelesaian teknis yang runut dan mudah dipahami:
  - **Masalah Voice Channel / Suara Lag**:
    1. Periksa ping Discord (indikator sinyal di pojok kiri bawah).
    2. Sarankan moderator untuk mengganti *Voice Region / RTC Region* ke region terdekat (misal: Singapore / Sydney).
    3. Cek pengaturan input/output mic di Discord Settings > Voice & Video.
    4. Coba matikan/hidupkan fitur *Noise Suppression (Krisp)*.
  - **Channel Tidak Kelihatan / Akses Terkunci**:
    1. Pastikan user sudah memiliki role yang sesuai (cek channel roles).
    2. Sarankan user me-refresh Discord (`Ctrl + R` di Desktop).
  - **Kendala Perintah Bot**:
    1. Pastikan menggunakan slash command `/` (bukan prefix teks lama).
    2. Cek apakah bot memiliki izin di channel tersebut.
- Jika masalah berlanjut di luar kendali user, sarankan membuat tiket atau melaporkan ke admin.
